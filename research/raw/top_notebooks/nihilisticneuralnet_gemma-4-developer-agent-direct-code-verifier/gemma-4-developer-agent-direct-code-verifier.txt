## 4. Configuration and archive checks

The control must reproduce the exact ZIP hash printed by the attached 0.22 notebook. Sampling and evaluation YAML must match it byte-for-byte for every candidate. The loader checks local includes, declared tool sets, supported model alias and accidental state placeholders.

Stage/call thresholds and test-output handling are agent instructions. The deterministic builder enforces only config/ZIP properties; it cannot enforce model behavior.

FULL_TOOLS=set(['run_command','read_file','edit_file','write_file','get_status','submit_patch',
                'get_code_neighbors','search_similar_code','get_code_subgraph'])
LEAN_TOOLS=FULL_TOOLS-set(['get_code_neighbors','search_similar_code','get_code_subgraph'])
BUDGET=dict(timeout_seconds=240,max_tool_calls=28,max_time_minutes=8,max_turns=80)
SAMPLING=yaml.safe_load(BASELINE_FILES['configs/sampling.yaml'])

def validate(name,files):
    assert set(files)==set(BASELINE_FILES)
    for relative in ('configs/sampling.yaml','eval_config.yaml'):
        assert files[relative]==BASELINE_FILES[relative]
    class Loader(yaml.SafeLoader):pass
    def include(loader,node):
        target=Path(loader.name).parent/loader.construct_scalar(node)
        assert not target.is_absolute() and '..' not in target.parts
        relative=target.as_posix();assert relative in files
        if target.suffix=='.md':return files[relative]
        child=Loader(files[relative]);child.name=relative
        try:return child.get_single_data()
        finally:child.dispose()
    Loader.add_constructor('!include',include)
    loader=Loader(files['agent.yaml']);loader.name='agent.yaml'
    try:agent=loader.get_single_data()
    finally:loader.dispose()
    assert agent['model']=='gemma-4-31b-it-qat-w4a16-ct'
    assert agent['instruction']==files['prompts/system.md']
    expected=LEAN_TOOLS if name in ('lean_tools','combined') else FULL_TOOLS
    assert set(agent['tools'])==expected
    assert agent['generate_content_config']==SAMPLING
    assert yaml.safe_load(files['eval_config.yaml'])['evaluation']==BUDGET
    assert not re.search(r'\{[^{}]+\}',agent['instruction'])
    return agent

def package(name,files,path):
    validate(name,files)
    with zipfile.ZipFile(path,'w') as archive:
        for relative,content in sorted(files.items()):
            entry=zipfile.ZipInfo(relative,date_time=(1980,1,1,0,0,0))
            entry.compress_type=zipfile.ZIP_DEFLATED;entry.external_attr=0o100644<<16
            archive.writestr(entry,content.encode())
    with zipfile.ZipFile(path) as archive:
        assert archive.testzip() is None
        assert set(archive.namelist())==set(files)
        for relative,content in files.items():assert archive.read(relative)==content.encode()
    return hashlib.sha256(path.read_bytes()).hexdigest()

## 5. Tool-use mechanics made concrete

- **Search:** the harness truncates command output at 5,000 characters, so a shorter labeled result is more useful than a broad search whose useful tail disappears.
- **Editing:** independent exact replacements can share a Python command, but every old substring must be validated before any file is written. A failed match should leave the checkout untouched.
- **Verification:** pytest's final failure details often appear after its progress/header output. Capturing the output and preserving its original exit code avoids losing the useful traceback or treating `tail` success as test success.
- **Finishing:** `get_status.patch_size` describes submitted state. An unsent source edit can exist even when this field is zero. `git add -N .` exposes genuinely new source files to the final diff; `submit_patch` remains terminal.

These are ways to use existing tools, not extra declarations that the closed registry cannot compile.
